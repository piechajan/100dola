2. Vyplň NAP + kategorie + popis + otevírací dobu + fotky (viz výše).
3. **Ověření:** Seznam ověří firmu telefonicky/SMS na číslo provozovny (+420 739 045 057) —
   měj telefon po ruce.
4. Po schválení se firma objeví i na **Mapy.cz** (Mapy berou data z Firmy.cz).
