## Jak si vybrat A / B / C

| Vzhled | Kdy zvolit | Očekávaná open rate | Očekávaná CTR |
|---|---|---|---|
| **A — Hero + benefits** | Standard / mix audience, jsi-li na rychlou jasnou zprávu | 28-35 % | 6-9 % |
| **B — Vizuální produkt-fokus** | Zákazníci co kupují očima, retargeting, lidé co už ví o značce SCOTT | 25-32 % | 8-12 % (FOMO efekt) |
| **C — Editoriální** | Loyalty list, dlouhodobí čtenáři magazínu, hlubší vztah | 35-45 % | 4-7 % (méně CTR, ale vyšší kvalita leadu) |

**Recommendation:** Pokud Tvůj seznam je míchaný (B2C cyklisté + sport zákazníci + loyalty), pošli **A** primary + retarget na neopen → **C** za 4 dny.

---

## Co testovat

- **A/B subject** — pošli A vs B / 50:50 split, 4 hodiny sběru open-rate, pak winner na zbytek seznamu
- **Send time** — úterý-čtvrtek **7:30-9:00** (ranní commuting/coffee) NEBO **18:00-20:00** (večerní wind-down)
- **Hero image** — místo statického foto zkus animovaný GIF (3 fotky střídání) — některé email klienti GIF nepřehrají, ale fallback funguje

## Resend programmatic send

```ts
import { Resend } from "resend";
const resend = new Resend(process.env.RESEND_API_KEY);

const html = `<!-- HTML z vybraného vzhledu A/B/C -->`;
const subject = "Nový Scott Spark RC 2027 je tady. Předobjednávka už běží.";

await resend.batch.send(
  recipients.map((r) => ({
    from: process.env.RESEND_FROM_EMAIL!,
    to: r.email,
    subject,
    html: html.replace("{{unsubscribe_url}}", r.unsubscribeUrl),
    tags: [
      { name: "campaign", value: "spark-rc-2027-launch" },
      { name: "design", value: "A" }, // nebo B, C
      { name: "audience", value: "newsletter" },
    ],
  })),
);
```
