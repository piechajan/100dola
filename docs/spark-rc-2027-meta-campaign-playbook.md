## Společné — co sledovat každý den

### Klíčové KPIs

| Metric | Target (2 dny, 2k Kč) |
|---|---|
| Impressions | 30 000 – 80 000 |
| Clicks | 200 – 800 |
| CTR | > 1 % |
| CPC | 2.50 – 5 Kč |
| Landing page views | 80 % click-through ratio |
| Spark RC PDP views (Custom Conversion) | sleduj v Events Manager |
| Předobjednávky (Lead) | 1–5 leadů cíl |
| Cost per Lead (CPL) | < 500 Kč |

### Kde sledovat
- **Ads Manager:** Reportováno v real-time, refresh každých 30 min
- **Events Manager:** [https://business.facebook.com/events_manager2/list/dataset/1867612187213152/overview?business_id=1362363054962597](https://business.facebook.com/events_manager2/list/dataset/1867612187213152/overview?business_id=1362363054962597)
  - Sleduj „Spark RC 2027 — návštěva" + „Spark RC 2027 — předobjednávka"
- **GA4:** [https://analytics.google.com/](https://analytics.google.com/) — sleduj `utm_campaign=spark-rc-2027-launch-jun11`

### Pokud kampaň neperformuje
- **CTR < 0.5 %:** creative se nelíbí → zkus jiný image nebo lepší primary text
- **CPC > 10 Kč:** audience moc úzká → rozšiř na celou ČR
- **0 leadů po 1 dni:** Lead = vysoký intent, je to OK pro Traffic kampaň. Sleduj Spark RC PDP views jako primary KPI.
